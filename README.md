# Stage Timer — FFGL-плагин таймера для Resolume Arena / Avenue

Source-плагин (генератор) с таймером для сцены, суфлёра или экрана в зале. Три режима работы:

- **Timer (From > To)** — отсчёт от одного времени до другого. Если From больше To, таймер считает **вниз** (05:00 → 00:00). Если меньше — **вверх** (00:00 → 05:00). Кнопка **Swap From/To** меняет направление в одно нажатие. Подходят любые пары, например 10:00 → 07:30.
- **Until Time of Day** — обратный отсчёт до времени суток: «до начала в 19:30».
- **Clock** — текущее время компьютера.

Шрифты встроены в плагин, ничего дополнительно ставить не нужно.

## Установка

- **Windows:** скопировать `StageTimer.dll` в `Documents\Resolume Arena\Extra Effects\`.
- **macOS:** скопировать `StageTimer.bundle` в `~/Documents/Resolume Arena/Extra Effects/`, затем снять карантин:
  ```
  xattr -dr com.apple.quarantine ~/Documents/Resolume\ Arena/Extra\ Effects/StageTimer.bundle
  ```

Перезапустить Arena → **Sources** → **Stage Timer**.

## Как вводить время

Поля From, To, Warning At и Critical At — текстовые. Понимают любой из форматов:

| Ввод | Значение |
|---|---|
| `00:05:00`, `5:00`, `300` | 5 минут |
| `1:30:00`, `90:00`, `1h30m`, `1ч 30м` | полтора часа |
| `2m 30s`, `2 мин 30 сек`, `150` | 2 мин 30 с |
| `1:30.5` или `1:30,5` | 1 мин 30,5 с |

В режиме Until Time of Day поле To называется **Target Time** и принимает время суток: `19:30`, `19:30:15`, `1930`, `7:30 pm`. Если это время прошло меньше 12 часов назад, таймер считает его наступившим. Если больше — считает, что имеется в виду завтра.

## Параметры

**Timer**

| Параметр | Что делает |
|---|---|
| Mode | Timer / Until Time of Day / Clock |
| From, To | Начало и конец отсчёта (направление определяется автоматически) |
| Start/Pause | Одна кнопка: старт или пауза. Нажатие после окончания запускает заново |
| Start, Pause, Reset | Отдельные кнопки |
| Running | Переключатель «идёт / стоит». Отражает реальное состояние, сбрасывается сам, когда таймер дошёл до конца |
| Swap From/To | Поменять From и To местами (обратный отсчёт ↔ прямой) |
| +1 Min / −1 Min | Добавить или отнять минуту у оставшегося времени прямо на ходу |
| At End | **Stop** — остановиться; **Stop & Flash** — остановиться и мигать; **Loop** — начать заново; **Continue (overtime)** — считать дальше в минус (−00:12), цветом Critical |
| Restart On Trigger | Запускать с начала при каждом запуске клипа (подробности ниже) |

Все кнопки — обычные параметры Resolume, их можно назначить на MIDI, OSC или клавиатуру.

**Display**

| Параметр | Что делает |
|---|---|
| Format | Auto (`1:05:00` или `05:00`) / HH:MM:SS / MM:SS (минуты больше 59: `90:00`) / Seconds / HH:MM |
| Fraction | Без долей / 1/10 с / 1/100 с |
| Font | Sans Bold / Sans Light / Mono / **Digital (7-segment)** |
| Ghost Segments | Для Digital: яркость «погасших» сегментов, как у настоящего табло |
| Blink Colon | Мигающее двоеточие, пока таймер идёт |
| Label, Label Size, Label Position | Подпись над или под цифрами («ДО НАЧАЛА», «SPEAKER TIME»). Кириллица поддерживается |
| Size, Position X/Y | Размер (100 % = почти на всю ширину) и положение центра |
| Shadow | Тень под текстом, для читаемости поверх видео |

**Colors**

| Параметр | Что делает |
|---|---|
| Text Color | Основной цвет (белый) |
| Warning At + Warning Color | С какого остатка цифры желтеют (по умолчанию 1:00) |
| Critical At + Critical Color | С какого остатка краснеют (по умолчанию 0:10). Этим же цветом показывается overtime |
| Flash Overtime | Мигать в overtime |
| Background | Цвет и прозрачность фона. По умолчанию фон прозрачный, таймер можно класть слоем поверх контента |

Пустое поле Warning At или Critical At выключает соответствующий порог. Пороги считаются от **оставшегося до To** времени, в обе стороны: при отсчёте вверх 00:00 → 45:00 цифры пожелтеют на 44:00.

**Progress Bar** — Off / Under Timer / Screen Bottom / Screen Top, плюс Bar Height. При обратном отсчёте полоса показывает остаток, при прямом — сколько прошло. Цвет полосы следует за цветом цифр.

## Как идёт время

- Таймер считает по реальным часам компьютера, а не по кадрам. Если клип убрали с экрана, таймер продолжает идти, и при возврате покажет правильное время.
- **Restart On Trigger** (по умолчанию выключен): если кадры не рисовались больше секунды (клип был остановлен), при следующем запуске клипа таймер сбрасывается и стартует сам. Удобно для «запустил клип — пошёл отсчёт». Не включайте, если клип может надолго скрываться посреди отсчёта.
- Изменение From сбрасывает таймер. Изменение To — нет, его можно подвинуть на ходу.
- Цифры стоят в ячейках фиксированной ширины, поэтому текст не дрожит при смене цифр.

## Сборка из исходников

Нужны CMake 3.20+ и Visual Studio 2019+ (Windows) или Xcode (macOS). FFGL SDK и GLEW скачиваются автоматически.

```
# Windows
cmake -B build -A x64
cmake --build build --config Release

# macOS (universal: Apple Silicon + Intel)
cmake -B build -G Xcode
cmake --build build --config Release
```

Результат — в `build/dist/`. Через GitHub: workflow `.github/workflows/build.yml` собирает Windows- и macOS-версии и прогоняет тесты (Actions → Artifacts).

Юнит-тесты логики (парсинг, направления, окончание, overtime, время суток): `-DSTAGETIMER_BUILD_TESTS=ON`, затем запустить `timer_tests`.

## Устройство

- `src/FFGLTimer.*` — плагин: параметры, раскладка, шейдер (цвета, тень, сегменты, полоса прогресса).
- `src/TimerLogic.*` — логика без графики: разбор ввода, состояние, форматирование.
- `src/TextRasterizer.*` — растеризация текста через stb_truetype, цифры в ячейках фиксированной ширины.
- `src/fonts/` — встроенные шрифты.
